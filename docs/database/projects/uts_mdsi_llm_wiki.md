# Project: UTS MDSI LLM Wiki

## 📋 Overview
A persistent course-material knowledge base and documentation vault for the UTS Master of Data Science and Innovation program. The repository curates subject course files and structures them into an LLM-readable format, serving as a tutor, synthesis engine, and assignment review partner.

* **GitHub Repository:** https://github.com/tuannm3812/uts-mdsi
* **Tier:** Tier 2 (Strong Applied Project)
* **Target Roles:** Knowledge Management Specialist, Prompt Engineer, AI Operations Developer, Technical Writer

---

## 🛠️ Technical Stack
* **Formats:** Markdown, Obsidian Vault structural conventions
* **AI Tooling:** Prompt Library, context-injected LLM interfaces
* **Subjects Covered:** Data Science for Innovation, Statistical Thinking, Machine Learning Algorithms, Applied NLP, Data Visualization

---

## ⚙️ Architecture & Implementation details
1. **Curated Wiki Layer:**
   - Maps subjects from Google Drive files into localized Markdown index files.
   - Cleans raw course PDF/doc text into standardized LLM-ingestable notes.
2. **Operations & Assessment Mapping:**
   - Integrates assessment calendars, subject timelines, and assignment requirements.
3. **Master Prompt Library:**
   - Configures reusable system prompts tailored to course subjects, acting as specialized virtual tutors for coding, logic, and synthesis.

---

## 💡 Key Challenges & Solutions
* **Challenge: Handling Fragmented Course Sources.** Lecture slides, code notebooks, and readings are often scattered across Google Drive.
  * **Solution:** Standardized subject sub-folders and added a root Course Map that links and indexes all active curriculum areas.

---

## 📈 Impact & Key Metrics
* **Efficiency:** Dramatically accelerated exam revision and assignment outlining via local LLM synthesis.
* **Organization:** Centralized 4 semesters of master's coursework into a single, searchable Git-backed vault.
